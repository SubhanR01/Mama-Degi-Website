# Mama Degi – Website

Ein-Seiten-Website für Mama Degi (ماما دیگی چرگه او بریانی), Kabul.

## Öffnen
- Doppelklick auf `index.html` öffnet die Seite im Browser.
- Besser (Videos + weiches Scrollen laufen zuverlässiger): im Terminal in diesem Ordner
  `python3 -m http.server 8000` ausführen und http://localhost:8000 öffnen.

## Inhalt
- `index.html` – gesamter Code (HTML, CSS, JavaScript in einer Datei)
- `hero-desktop.mp4` – Hero-Video 16:9 (Computer)
- `hero-mobile.mp4` – Hero-Video 9:16 (Handy)
- `img/` – Logo, Fotos und Menübilder

## Technik
- GSAP 3.12.5 + ScrollTrigger (cdnjs) für Scroll-Animationen
- Lenis 1.1.13 (jsdelivr) für weiches Scrollen
- WebGL-Shader für den Dampf, Canvas für die Glut-Funken
- Schriften: Bodoni Moda, Manrope, Vazirmatn, DM Mono (Google Fonts)

## Online stellen
Den ganzen Ordner auf einen beliebigen Static-Host hochladen (z. B. Netlify Drop, Vercel, GitHub Pages, cPanel).
Bei Netlify: https://app.netlify.com/drop öffnen und den Ordner hineinziehen.
